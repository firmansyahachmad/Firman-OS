# Firman.OS

Smart motorcycle dashboard for Android.

Firman.OS is an experimental low-cost motorcycle dashboard designed for an Android phone/tablet mounted on the bike while the user's primary phone stays safely stored.

## V0.1

- Landscape riding dashboard
- Live GPS speed
- Trip duration
- Trip distance
- Estimated fuel consumption
- Estimated fuel cost
- Google Maps navigation handoff
- Android-first architecture

Next: route/ETA, traffic information, richer ride UI, notification integration, trip history, and configurable vehicle/fuel profiles.
